# Analysis rubric

Evaluate each source along these dimensions:

1. **Identity** — title, authors or publisher, date, version, venue, and source type.
2. **Question and claim** — the problem addressed and the strongest claims made.
3. **Method** — design, model, data, baselines, controls, metrics, and assumptions.
4. **Evidence** — which results support each claim; note missing tables, appendices, or inaccessible data.
5. **Validity** — confounders, leakage, selection bias, statistical weakness, inappropriate baselines, and overgeneralization.
6. **Reproducibility** — code, data, hyperparameters, licenses, hardware, and procedural detail.
7. **External consistency** — agreement or conflict with primary sources when cross-source verification is requested.
8. **Practical relevance** — applicability, integration cost, operational risk, and expected value for the stated project.
9. **Confidence** — high, medium, or low, with the evidence that justifies the rating.

Run a second pass that challenges the first conclusion. Preserve uncertainty when the source cannot resolve it.
